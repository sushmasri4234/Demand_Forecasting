A **production-ready Flask application** with:

- ✅ Comprehensive security (Argon2, rate limiting, CSRF, audit logging)

- ✅ Email notifications
- ✅ Docker deployment ready

## 🎯 Quick Start (5 Minutes)

### Step 1: Run Setup Script

```bash
python setup_auth.py
```

This creates all directories, generates secure keys, and creates initial templates.

### Step 2: Install Dependencies

```bash
pip install -r requirements_auth.txt
```

### Step 3: Generate Templates

```bash
python generate_templates.py
```

### Step 4: Configure Email (Optional for testing)

Edit `.env` file:
```
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
```

For Gmail, generate an App Password: https://myaccount.google.com/apppasswords

**Note**: Email is optional for local testing. You can skip verification by manually activating users in the database.

### Step 5: Initialize Database

```bash
set FLASK_APP=run.py
flask db init
flask db migrate -m "Initial migration"
flask db upgrade
```

### Step 6: Run Application

```bash
python run.py
```

Access at: **http://localhost:5000**

### Step 7: Login

**Default Admin Account:**
- Email: `admin@demandforecasting.com`
- Password: `Admin@123456`

**⚠️ CHANGE THIS PASSWORD IMMEDIATELY!**

## 🛠️ Configuration

### Environment Variables (.env)

Key settings to configure:

```bash
# Security Keys (auto-generated by setup script)
SECRET_KEY=<generated>
ARGON2_SECRET_KEY=<generated>
TOTP_ENCRYPTION_KEY=<generated>

# Email (configure for your SMTP server)
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password

# Database (SQLite for development, PostgreSQL for production)
DATABASE_URL=sqlite:///demand_forecasting.db

# Redis (optional, uses memory:// by default)
REDIS_URL=redis://localhost:6379/0
```

## 🔧 Troubleshooting

### Database Errors

```bash
# Reset database
flask db downgrade
flask db upgrade
```

### Email Not Sending

1. Check SMTP credentials
2. For Gmail, use App Password
3. Check logs: `logs/app.log`
4. Test SMTP connection

### Import Errors

```bash
# Reinstall dependencies
pip install -r requirements_auth.txt --force-reinstall
```

### Port Already in Use

```bash
# Change port in run.py
app.run(port=5001)
```

### Redis Connection Error

```bash
# Use memory storage
# In .env:
RATELIMIT_STORAGE_URL=memory://
```

## 📚 API Endpoints

### Authentication
- `POST /auth/register` - Register new user
- `GET /auth/verify-email` - Verify email
- `POST /auth/login` - Login
- `GET /auth/logout` - Logout
- `POST /auth/forgot-password` - Request password reset
- `POST /auth/reset-password` - Reset password
- `GET /auth/account` - User account page
- `POST /auth/account/change-password` - Change password
- `GET /auth/2fa/setup` - Setup 2FA
- `POST /auth/2fa/disable` - Disable 2FA
- `GET /auth/admin/users` - Admin user list

### Forecasting
- `GET /` - Homepage
- `POST /upload` - Upload CSV data
- `POST /train` - Train model
- `GET /models` - List models
- `POST /predict` - Generate predictions
- `GET /dashboard` - Interactive dashboard
